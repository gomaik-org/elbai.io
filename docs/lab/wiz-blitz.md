# Synergien mit dem Wiz-Blitz Framework

Das modulare **Wiz-Blitz Framework** (`/Users/binary/Documents/code/frameworks/wiz-blitz`) dient als architektonische Blaupause für die tooling- und agentenbasierte Entwicklung bei ELBI.

---

## Kernbausteine & Übertragbarkeit

- **MCP-Native Architektur:** Einbindung von Tools via Model Context Protocol (JSON-RPC).
- **Security-First Pipeline:** Automatisierte Checks mit Wiz CLI direkt vor jedem Release.
- **FinOps & Scale-to-Zero:** Verhindert laufende Fixkosten durch ephemere Workloads auf Cloudflare und Cloud Run Jobs.
- **Living Documentation:** Automatisierte Generierung von Architektur-Dokumentationen via MkDocs for Material.
