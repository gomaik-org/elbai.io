# elbi.de Storefront & D1 Edge-Datenbank

Die Plattform `elbi.de` wurde von einem monolithischen Altsystem in eine hochperformante, moderne Edge-Architektur überführt.

---

## Technische Highlights

- **Framework:** Astro 7+ mit Zero-JS SSG (HTML pur für Produkt- und Kategorieseiten)
- **Dynamische Inseln:** React 19 für interaktiven Warenkorb (`Island Architecture`)
- **Styling:** Tailwind CSS v4
- **Performance:** 96 Seiten statisch vorkompiliert, Lighthouse 100/100, TTFB &lt; 50ms
- **Rechtskonformität:** Vollständige Einhaltung aller Vorgaben des deutschen E-Commerce (§ 356a BGB Widerrufsbutton, § 312j BGB Button-Lösung, PAngV, GPSR und BFSG Barrierefreiheit).
